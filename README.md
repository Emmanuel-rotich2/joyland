# FGCK Joyland

A church appointment booking and member management system for FGCK Makutano West Joyland.

## Features
- Member appointment booking
- Pastor dashboard and appointment management
- Event and announcement notifications
- Email and SMS integration
- Availability scheduling

## Stack
- PHP
- MySQL
- Bootstrap-based UI

## Getting started
1. Configure the database connection in `config/database.php`.
2. Import the SQL schema from `database/schema.sql`.
3. Configure email and SMS settings in `config/email.php` and `config/sms.php`.
4. Run the app via a local PHP web server or Apache/NGINX setup.

## Notes
This project is designed for a church appointment workflow and is intended for local deployment and GitHub hosting.
